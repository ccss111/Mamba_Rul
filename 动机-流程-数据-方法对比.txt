
======================================================================
基于 GAT-Mamba 与 CQR 的可靠性导向航空发动机 RUL 预测方法
======================================================================

一、研究背景与问题定义
----------------------------------------------------------------------

航空发动机剩余使用寿命（Remaining Useful Life，RUL）预测是预测性维护和健康管理系统中的核心任务。所谓 RUL，是指发动机从当前观测时刻开始，到其发生失效或达到不可接受性能状态之前所剩余的运行周期数。与简单的故障分类不同，RUL 预测不仅需要判断发动机是否正在退化，还需要回答“还能够安全运行多久”这一具有连续数值和强风险属性的问题。

在实际运行过程中，发动机健康状态不能直接观测，只能通过温度、压力、转速、流量等传感器信号间接推断。不同传感器通常对应不同的部件或物理过程，它们之间存在耦合关系；同时，发动机退化过程具有明显的时间连续性、阶段性和非平稳性。早期阶段的传感器变化可能十分微弱，中后期则可能出现加速退化、局部突变或多变量协同变化。因此，一个有效的 RUL 预测模型至少需要同时解决以下三个问题：

1. 如何从多传感器数据中提取具有物理关联意义的空间特征；
2. 如何从连续运行序列中识别长期退化趋势与局部动态变化；
3. 如何量化预测结果的不确定性，并使预测误差与实际维护风险相匹配。

本文面向 NASA C-MAPSS（Commercial Modular Aero-Propulsion System Simulation）数据集，提出一种以可靠性为导向的 GAT-Mamba-CQR 剩余寿命预测框架。该框架并不只追求单一 RUL 数值的平均误差最小，而是同时考虑传感器空间关系、长时间序列建模、非对称预测风险和预测区间覆盖能力，最终输出点预测结果以及能够反映预测可信程度的 RUL 区间。


二、现有方法的局限与模型提出动机
----------------------------------------------------------------------

2.1 传统 GAT、LSTM 与注意力模型的优点

已有研究通常将图注意力网络（Graph Attention Network，GAT）、长短期记忆网络（Long Short-Term Memory，LSTM）以及注意力机制结合起来进行 RUL 预测。GAT 可以将不同传感器视为图中的节点，并通过注意力权重学习节点之间的重要性关系，因此比简单拼接传感器变量更适合处理多变量耦合问题。LSTM 通过门控结构保存历史信息，能够建模发动机退化的时间依赖关系。AEF 或其他注意力机制则可以对不同时间步或不同隐状态进行加权，帮助模型关注与当前寿命判断最相关的退化片段。

这类模型为 RUL 预测提供了较好的基础：GAT 负责“不同传感器之间如何相互影响”，LSTM 负责“健康状态如何随时间演化”，注意力机制负责“哪些特征和时间片段更重要”。但是，当序列变长、工况复杂、噪声增强或退化规律出现变化时，单纯依赖 GAT+LSTM+注意力仍然存在明显不足。

2.2 LSTM 在长序列建模中的局限

第一，LSTM 本质上是递归式序列模型。当前时刻的隐状态依赖上一时刻的隐状态，整个序列需要按照时间顺序逐步计算。当输入序列较长时，信息需要经过多次递归传递，早期退化信息可能在传播过程中逐渐衰减。尽管 LSTM 通过输入门、遗忘门和输出门缓解了普通循环网络的梯度消失问题，但它并不能完全消除长期依赖建模困难。

对于航空发动机退化序列而言，早期的轻微变化可能是后续严重退化的重要先兆。如果模型只保留靠近当前时刻的信息，就可能忽略较早阶段的退化趋势；如果模型试图长期保存全部历史信息，又可能引入大量冗余和噪声。LSTM 的递归计算还限制了序列处理的并行性，使得模型在序列长度增加时计算效率和特征更新速度受到影响。

当 LSTM 与 GAT、AEF 共同使用时，GAT 输出的空间融合特征需要再通过递归结构进行时间压缩。如果空间特征的变化速度与 LSTM 的记忆更新方式不匹配，可能造成两个问题：一是图网络提取出的细粒度传感器交互信息在递归传递中被平滑；二是 LSTM 对长期趋势的记忆与 AEF 的加权聚合之间存在重复或竞争，导致特征利用效率下降。因此，有必要引入更适合长序列、同时能够保留局部变化的时序建模模块。

2.3 对称点预测与真实维护风险不一致

第二，传统点预测通常采用均方误差（MSE）或平均绝对误差（MAE）等对称损失函数。这类损失默认预测值高于真实 RUL 和低于真实 RUL 的代价相同，但航空发动机维护场景并不满足这一假设。

设真实 RUL 为 y，预测 RUL 为 y_hat，误差为 e = y_hat - y：

	e > 0：模型高估 RUL，认为发动机比实际更加健康，可能造成延迟维护或延迟预警；
	e < 0：模型低估 RUL，认为发动机比实际更加危险，可能造成过早维护或资源浪费。

两种错误都需要被控制，但风险侧重点可以不同。在安全关键的航空发动机应用中，过度高估寿命可能带来更严重的安全风险，尤其是在真实 RUL 已经较低的退化后期。因此，模型不应只学习总体平均误差，还应当根据误差方向和发动机所处退化阶段调整惩罚强度。

2.4 单一预测值无法表达可靠程度

第三，在复杂工况、传感器噪声、训练样本有限以及不同发动机退化模式存在差异的情况下，模型预测本身必然包含不确定性。若模型只输出一个 RUL 数值，例如“还剩 35 个周期”，使用者无法判断这个结果是高度可信，还是模型在缺乏相似训练样本时给出的低置信度估计。

单一数值不能区分以下情况：

	预测值为 35，区间为 [34, 36]：模型较为确定；
	预测值为 35，区间为 [15, 58]：模型对当前状态存在较大疑虑。

这两个预测的点值相同，但维护决策意义完全不同。因此，RUL 模型应当同时输出点预测和预测区间，用区间宽度、覆盖率等指标描述模型对预测结果的可信程度。基于这一需求，本文将不确定性建模纳入模型训练目标，而不是在点预测完成后简单附加一个统计量。


三、为什么提出 GAT-Mamba-CQR 模型
----------------------------------------------------------------------

本文提出该模型的根本原因，是希望在一个统一框架中解决“空间关联、长期时序、风险不对称和结果可信度”四个相互联系的问题。

3.1 Mamba 替代 LSTM 的必要性

Mamba 是一种基于选择性状态空间模型（Selective State Space Model，Selective SSM）的序列建模方法。它通过状态空间更新机制压缩和传递历史信息，并根据输入内容选择性地保留或抑制不同信息。与传统循环网络逐时间步递归更新不同，Mamba 更适合对长序列进行高效建模，在捕获长期趋势的同时，也能够保留局部变化。

在发动机退化建模中，Mamba 的引入主要有以下意义：

1. 对长时间退化趋势进行建模。发动机从健康状态到失效状态是一个跨多个运行周期的渐进过程，Mamba 能够在状态空间中保留较长时间范围内的有效信息。
2. 关注具有判别力的历史片段。并非所有时间步对当前 RUL 都同样重要，选择性状态更新有助于减弱冗余观测和噪声的影响。
3. 兼顾全局趋势与局部波动。发动机退化曲线可能同时存在缓慢下降趋势和短期传感器波动，Mamba 的状态空间结构能够对两类模式进行统一表示。
4. 改善长序列计算效率。Mamba 不依赖传统 LSTM 的逐步隐状态递归方式，在长序列场景下具有更好的扩展潜力。

因此，本文采用 Mamba 编码器和 Mamba 解码器构成时序建模主体，形成 Encoder-Decoder 结构。编码器负责将输入窗口压缩为包含历史退化信息的序列表示，解码器进一步对编码后的时序特征进行重构和融合，并提取用于 RUL 预测的最终特征。

3.2 保留 GAT 的必要性

虽然 Mamba 擅长时间维度建模，但它本身并不显式描述不同传感器变量之间的结构关系。如果直接将全部传感器变量拼接后输入 Mamba，模型需要同时从大量通道中自行学习变量间关系，容易受到冗余信息和噪声的影响。

因此，本文保留 GAT 作为空间特征提取模块。每个时间步的传感器变量被视为图节点，节点之间的边表示潜在的传感器关联。模型使用传感器嵌入计算节点相似性，并通过动态 K 近邻方式构造邻接关系；随后，图注意力层根据中心节点与邻居节点的特征学习注意力权重，对多传感器信息进行聚合。

为了避免图卷积过度平滑导致原始信号丢失，当前实现还保留了两条互补路径：一条是 GAT 提取的空间融合特征，另一条是原始传感器值经过线性变换得到的特征。模型通过门控机制自适应融合两者，使输出既包含传感器之间的交互关系，又保留原始变量中的有效信息。这种设计适合传感器之间关联随健康状态变化的场景。

3.3 引入非对称损失的必要性

为了使模型目标与实际维护风险保持一致，本文在点预测分支使用风险自适应的非对称损失。其基本形式可以写为：

	L_asym = mean(w_i * (y_hat_i - y_i)^2)

其中，w_i 根据预测误差方向、真实 RUL 所处阶段以及数据集特征进行调整。当模型高估 RUL 时，增加相应惩罚；当真实 RUL 低于退化关注阈值时，进一步提高样本权重；对于处于健康高 RUL 上限附近的样本，则适当抑制其权重，避免大量健康样本主导训练过程。

在当前实现中，非对称权重可以抽象表示为：

	w_i = (1 + alpha * I(e_i > 0))
		  * (1 + gamma * I(y_i < threshold_focus))
		  * (1 - (1 - delta) * I(y_i >= threshold_cap))

其中 alpha 控制高估惩罚强度，gamma 控制低 RUL 样本的关注程度，delta 控制高 RUL 截断区域的权重，I(.) 为指示函数。由于不同子数据集的运行工况和退化模式不同，FD001、FD002、FD003 和 FD004 可以采用不同的风险参数。

3.4 引入 CQR 的必要性

本文采用保序共形回归（Conformalized Quantile Regression，CQR）生成 RUL 预测区间。CQR 将分位数回归和共形预测相结合，先通过神经网络学习条件下分位数区间，再使用独立校准数据估计有限样本校准半径，最后对区间进行扩展，使其具有更可靠的覆盖能力。

CQR 的核心思想不是假设预测误差服从某个预先指定的概率分布，而是直接利用校准样本中的预测残差构造区间修正量。设模型输出未经校准的下界和上界为 q_low(x) 和 q_high(x)，真实标签为 y，则非对称区间误差分数可以定义为：

	s_i = max(q_low(x_i) - y_i,
			 y_i - q_high(x_i), 0)

在校准集上得到一组分数后，根据目标错误率 alpha 选取相应的高分位校准半径 q_hat。最终预测区间为：

	[q_low(x) - q_hat, q_high(x) + q_hat]

在当前 CQR 版本中，模型训练阶段使用上下分位数的 Pinball Loss 学习区间，测试或部署阶段再使用校准半径扩大区间。因此，模型输出的核心不是 Gaussian 假设下的“均值加减若干倍标准差”，而是数据驱动的上下分位数区间以及经过共形校准后的可靠预测区间。


四、模型总体结构与完整流程
----------------------------------------------------------------------

本文模型的完整流程可以概括为：

原始 C-MAPSS 数据
	-> 传感器筛选与预处理
	-> 标准化、平滑和 RUL 标签构造
	-> 滑动窗口生成时序样本
	-> 动态传感器图构建
	-> GAT 空间特征提取
	-> Mamba 编码器建模历史退化序列
	-> Mamba 解码器融合时序特征
	-> 点预测与 CQR 区间参数生成
	-> 联合损失训练
	-> 校准集估计 conformal 半径
	-> 输出点预测、预测区间和可靠性指标

4.1 C-MAPSS 数据组成

NASA C-MAPSS 数据集模拟了航空发动机从正常运行到最终失效的退化过程。数据按照 FD001、FD002、FD003 和 FD004 划分为四个子数据集。不同子数据集在运行工况数量、故障模式数量以及退化复杂程度方面存在差异：

	FD001：单一运行工况、单一故障模式；
	FD002：多运行工况、单一故障模式；
	FD003：单一运行工况、多故障模式；
	FD004：多运行工况、多故障模式。

每条发动机运行记录由发动机编号、运行周期、运行工况设置和多个传感器测量值组成。训练集包含发动机完整运行轨迹，测试集通常在发动机失效前截断，并提供每台测试发动机在截断时刻对应的真实 RUL 标签。

4.2 传感器筛选与预处理

首先读取训练集、测试集和测试 RUL 文件，按照字段含义建立数据表。部分传感器在数据中变化很小、信息重复较多或与目标退化关系较弱，预处理阶段可以删除这些低贡献变量，同时去除用于标识发动机和时间的索引字段，保留有效传感器特征。

为了减弱高频噪声并提取较平稳的退化趋势，当前流程支持指数平滑。指数平滑通过历史观测的加权组合得到平滑信号，较新的观测具有更大的权重。平滑率越大，曲线越平稳，但过度平滑也可能削弱突发退化信息，因此需要在实验中进行选择。

之后，使用训练集传感器数据拟合 StandardScaler，并用同一组训练集统计量变换训练集和测试集，避免测试信息泄漏。标准化后的特征具有相近的数值尺度，有利于 GAT 注意力计算和 Mamba 状态更新。

4.3 RUL 标签构造与截断

对于训练集中的每台发动机，先根据其最大运行周期计算每个时间点的剩余寿命：

	RUL(t) = T_failure - t

考虑到发动机早期阶段的真实 RUL 可能非常大，而早期传感器状态变化通常有限，流程采用分段线性 RUL 标签，将 RUL 截断到 max_RUL：

	RUL_capped(t) = min(RUL(t), max_RUL)

在默认设置下，max_RUL 为 125。随后将标签归一化到 [0, 1]：

	y(t) = RUL_capped(t) / max_RUL

模型内部在归一化空间训练，预测结果在评估和展示时再乘以 max_RUL 恢复为实际运行周期。这样可以避免 RUL 数值过大导致训练不稳定，同时保持不同数据集之间的数值尺度一致。

4.4 滑动窗口构造输入

对于每台发动机，使用长度为 L 的滑动窗口构造输入序列。当前实验默认 L=30，每个样本可表示为：

	X_t = [x_(t-L+1), ..., x_(t-1), x_t]

其中 x_t 表示时刻 t 的多传感器观测，X_t 的形状为 L * d，d 为保留的传感器数量，当前入口通常为 14 维。窗口末端时刻的 RUL 作为该窗口的监督标签。通过滑动窗口可以将一条发动机轨迹转化为多个带标签的局部退化片段，使模型学习从一段历史观测预测当前寿命。

对于测试发动机，若其有效观测长度不足一个完整窗口，则使用插值方法补齐序列；若长度足够，则生成末端窗口或多个测试窗口。最终既可以计算全测试窗口上的整体性能，也可以针对每台发动机最后一个观测窗口进行最终寿命预测。

4.5 动态传感器图与 GAT 空间建模

对于输入窗口中的每一个时间步，将 d 个传感器视为 d 个图节点。每个节点初始只有一个传感器标量值，节点之间的连接由可学习的传感器嵌入构造。具体来说，模型先对传感器嵌入进行归一化，再计算余弦相似度，并为每个节点选择 Top-K 相似节点形成动态 KNN 邻接矩阵。

对于邻接图中的节点 v，GAT 层根据节点特征计算邻居注意力权重，并对邻域信息进行加权聚合：

	h'_v = sigma(sum_{u in N(v)} alpha_(v,u) W h_u)

其中 alpha_(v,u) 表示节点 u 对节点 v 的影响程度，W 为可学习线性变换，sigma 为非线性激活函数。经过多层 GAT 后，所有传感器节点的表示被展平并压缩为一个空间融合向量，形成每个时间步的空间特征序列。

为了防止 GAT 层数增加后出现过度平滑，模型同时将原始传感器值进行线性投影，并通过门控融合空间特征和原始特征：

	h_space = GAT(X)
	h_raw = Linear(X)
	g = sigmoid(Linear([h_space; h_raw]))
	h_fused = g * h_space + (1-g) * h_raw

经过 LayerNorm 后，得到输入 Mamba 的时序特征序列。此时，传感器维度上的空间关系已经被编码到每个时间步的特征中。

4.6 Mamba 编码器

GAT 输出的空间特征序列输入 Mamba 编码器。编码器首先通过输入投影将特征维度映射到 Mamba 的 d_model，然后依次通过若干个 Mamba Block。每个 Block 采用 LayerNorm、Mamba 状态空间变换、Dropout 和残差连接：

	z = LayerNorm(x)
	m = Mamba(z)
	output = x + Dropout(m)

残差连接可以缓解深层网络训练中的信息损失，LayerNorm 有助于稳定不同时间步的特征分布。编码器输出保留整个窗口每个时间步的序列表示，同时使用末端状态构造编码状态，传递给解码器。

编码器的作用不是简单地取最后一个传感器观测，而是将窗口内的早期健康信息、中期退化趋势、末端局部波动和传感器交互变化共同编码起来。这样，模型可以学习“当前状态是什么”和“当前状态是如何演化到这里的”两类信息。

4.7 Mamba 解码器

在当前模型中，Mamba 解码器接收编码器输出的完整序列表示。解码器先将输入投影到自身的特征维度，再通过多层 Mamba Block 对编码序列进行进一步融合，最后取末端时间步的特征作为预测头输入。

编码器和解码器的职责有所不同：编码器重点提取历史序列中的退化状态表示，解码器重点对这些表示进行预测导向的重组。采用 Mamba 编码器-解码器结构，可以在不依赖传统 LSTM 递归记忆的情况下，充分利用窗口内的长期上下文。

4.8 点预测、上下分位数和预测区间输出

解码器输出的融合特征记为 h。当前 CQR 版本通过 interval_head 生成三个参数：下界参数、区间宽度参数和区间内点预测权重参数。

	a = interval_head(h)
	lower = sigmoid(a_1)
	width = sigmoid(a_2) * (1 - lower)
	upper = lower + width
	weight = sigmoid(a_3)
	point = weight * upper + (1-weight) * lower

上述参数化方式天然保证 lower <= upper，同时将区间限制在归一化 RUL 空间的合理范围内。point 是位于上下界之间的点预测结果，但它不应简单表述为 Gaussian 分布的均值；在当前实现中，它是由区间边界和可学习权重共同得到的区间内点估计。

模型还保留 Gaussian head 输出正值 sigma，用于提供额外的尺度信息或兼容 Gaussian 不确定性实验。但对于当前 test_GAT_EDmamba_CQR 入口，区间训练目标是 CQR 分位数损失，最终区间可靠性主要由分位数学习和 conformal 校准保证，而不是由 Gaussian 分布假设保证。

4.9 联合训练目标

当前模型使用点预测损失和 CQR 区间损失的加权和：

	L_total = (1-xi) * L_asym + xi * L_CQR

其中 L_asym 为风险自适应非对称 MSE，L_CQR 为上下分位数的 Pinball Loss。

对于分位数 tau，Pinball Loss 定义为：

	L_tau(q_tau, y) = max(tau*(y-q_tau), (tau-1)*(y-q_tau))

在目标区间错误率 alpha 下，下分位数和上分位数分别设置为：

	tau_lower = alpha / 2
	tau_upper = 1 - alpha / 2

例如，当 alpha=0.05 时，模型学习约 0.025 分位数和 0.975 分位数，对应目标覆盖水平约为 95%。CQR 区间损失不仅惩罚区间过宽，也惩罚真实标签落在区间之外的情况，使模型在覆盖率和区间紧致性之间取得平衡。

联合损失的意义在于：非对称损失负责让点预测符合维护风险，CQR 损失负责让区间包含真实 RUL 并保持尽可能窄。二者共同将训练目标从“只拟合一个数值”扩展为“预测一个风险敏感且具有可信区间的寿命结果”。

4.10 CQR 校准阶段

仅通过训练集上的分位数损失学习区间，并不能自动保证有限样本下的实际覆盖率。因此，训练完成后，使用独立校准数据计算每个样本的区间非一致性分数：

	s_i = max(lower_i - y_i, y_i - upper_i, 0)

如果真实标签落在预测区间内，s_i=0；如果真实标签落在区间外，s_i 等于超出区间的距离。根据校准样本数量和目标错误率 alpha，取这些分数的有限样本高分位数作为校准半径 q_hat。测试阶段将区间修正为：

	lower_calibrated = lower - q_hat
	upper_calibrated = upper + q_hat

最后再将归一化区间乘以 max_RUL，得到实际运行周期尺度的预测区间，并根据 [0, max_RUL] 进行截断。校准后的区间可以通过 PICP、PINAW 和区间得分等指标进行评价。


五、CQR 与 Gaussian 不确定性方法的比较
----------------------------------------------------------------------

5.1 Gaussian 不确定性建模的基本思想

Gaussian 方法通常假设给定输入 x 后，RUL 服从正态分布：

	y | x ~ N(mu(x), sigma(x)^2)

模型输出预测均值 mu 和标准差 sigma，通过 Gaussian Negative Log-Likelihood 训练：

	L_Gaussian = 0.5 * ((y-mu)^2 / sigma^2 + log(sigma^2))

在正态分布假设成立时，可以通过 mu +/- z * sigma 构造预测区间。例如 95% 区间通常取 z=1.96。然而，C-MAPSS 中的 RUL 分布往往具有截断、偏斜、非负、有上限和阶段性等特征，误差也不一定满足对称正态分布。因此，Gaussian 方法的效果较大程度依赖分布假设是否正确。

5.2 CQR 相对于 Gaussian 的优势

第一，CQR 不要求预测误差服从正态分布。Gaussian 方法将不确定性压缩为一个均值和方差，并通过固定分布形式推导区间；CQR 直接学习上下分位数，能够适应偏斜、厚尾、截断和多峰等非高斯误差分布。航空发动机 RUL 在退化后期可能具有明显偏斜，CQR 更容易表达这种非对称性。

第二，CQR 可以产生天然的非对称区间。Gaussian 区间通常围绕均值对称展开，即 [mu-z*sigma, mu+z*sigma]；但实际 RUL 的不确定性可能在上侧和下侧不同。例如，发动机临近失效时，预测值可能更容易高估，所需上侧保护范围与下侧范围并不相同。CQR 的下分位数和上分位数分别学习，不需要强制区间关于点预测对称。

第三，CQR 具有有限样本覆盖保证的思想。Gaussian 区间的覆盖率依赖模型是否正确估计 sigma，以及数据是否满足正态假设；即便输出了一个很小的 sigma，也不代表真实覆盖率可靠。CQR 在分位数模型基础上利用独立校准集估计 conformal 半径，能够根据实际残差对区间进行数据驱动修正，使目标覆盖率更具有统计意义。

第四，CQR 的区间宽度与样本难度相关。对于模型熟悉、传感器状态清晰的样本，区间可以较窄；对于复杂工况、强噪声或训练数据覆盖不足的样本，校准后的区间可以变宽，从而显式提醒使用者当前预测风险更高。Gaussian 方法也可以通过 sigma 表达这种差异，但 sigma 的数值含义依赖方差学习是否校准，CQR 的区间则直接服务于覆盖率目标。

第五，CQR 更适合 RUL 的边界约束。RUL 通常不应小于 0，并且在分段标签策略下不超过 max_RUL。Gaussian 分布在理论上允许产生负 RUL 或超过物理上限的 RUL，需要额外截断或变换；CQR 的分位数输出可以通过 sigmoid 和区间参数化直接限制在归一化范围内，再结合实际尺度截断，能够更自然地适应 RUL 的边界。

第六，CQR 可以与非对称风险目标组合。Gaussian NLL 主要根据概率密度和残差大小优化，天然倾向于对称误差表达；CQR 可以独立优化下分位数和上分位数，且点预测分支可以同时采用 Asymmetric Loss，从而分别处理区间覆盖风险和点预测方向风险。

需要说明的是，Gaussian 并非没有价值。Gaussian head 结构简单，适合误差近似对称、样本量较大且希望获得连续概率密度的场景；它也能够提供一个显式的尺度参数 sigma，便于构造概率似然。但在本文所面对的 C-MAPSS RUL 预测任务中，CQR 对分布假设更少，且更重视区间覆盖率和风险控制，因此作为主要不确定性方法更合适。


六、CQR 与 Monte Carlo Dropout 的比较
----------------------------------------------------------------------

6.1 Monte Carlo Dropout 的基本思想

Monte Carlo Dropout（MC Dropout）在测试阶段保持 Dropout 开启，对同一个输入进行多次随机前向推理，得到一组预测值：

	y_hat^(1), y_hat^(2), ..., y_hat^(M)

然后使用多次预测的均值和方差估计结果：

	mean = (1/M) * sum_m y_hat^(m)
	variance = (1/M) * sum_m (y_hat^(m) - mean)^2

多次预测之间的差异通常被解释为模型参数不确定性或 epistemic uncertainty 的近似。MC Dropout 不需要单独设计分布输出头，能够较方便地应用到已有神经网络中。

6.2 CQR 相对于 MC Dropout 的优势

第一，CQR 推理成本更低。MC Dropout 需要对每个样本进行 M 次随机前向计算，M 越大，均值和方差越稳定，但推理时间和显存开销也越高。CQR 通常只需要一次前向传播即可得到上下分位数，校准半径在部署前计算完成，更适合需要及时响应的在线健康监测场景。

第二，CQR 不依赖 Dropout 随机性来表达区间。MC Dropout 的区间质量受到 Dropout 位置、Dropout 概率、采样次数以及近似后验假设的影响。如果 Dropout 率选择不当，可能出现区间过窄或过宽。CQR 的区间直接由分位数预测和校准残差形成，参数含义更接近“目标覆盖率下的预测区间”。

第三，MC Dropout 主要反映模型参数不确定性，不能自动完整表达传感器噪声和条件异方差。对于相同输入附近的随机网络采样，它可能无法充分反映数据本身的噪声；通常还需要将 epistemic uncertainty 和 aleatoric uncertainty 分开设计。CQR 不需要事先明确区分这两类不确定性，而是直接校准最终预测误差，因此对实际部署中的综合误差更加实用。

第四，CQR 可以自然适应非对称和偏斜预测分布。MC Dropout 常见做法是对多次点预测计算均值和标准差，再构造近似对称区间。如果多次预测呈现偏斜，均值加减标准差并不能准确反映真实分布；CQR 直接学习下、上分位数，不要求区间对称。

第五，CQR 更容易进行覆盖率评价和控制。MC Dropout 产生的区间通常需要额外校准，否则名义上的 95% 区间未必在测试集上达到 95% 覆盖率。CQR 将校准步骤作为方法组成部分，通过校准集残差估计区间扩展量，能够直接围绕 PICP 等覆盖率目标进行设计。

MC Dropout 的优势在于实现方便，并且可以通过多次随机推理观察模型预测的稳定性；在研究模型集成、参数不确定性或缺乏校准集时，它仍然具有参考价值。但是，在本文关注的 RUL 安全风险和实时应用场景下，CQR 以单次推理、分布假设少、区间非对称和覆盖率可校准等特点更具优势。


七、CQR 与其他不确定性方法的总体对比
----------------------------------------------------------------------

八、可靠性导向模型的训练与推理过程
----------------------------------------------------------------------

训练阶段可以分为以下步骤：

步骤 1：读取 FD001-FD004 中指定子数据集的训练、测试和 RUL 文件。

步骤 2：删除低贡献传感器和非特征索引，对传感器数据进行指数平滑和 StandardScaler 标准化。

步骤 3：根据发动机最大运行周期计算训练 RUL，并执行 max_RUL 截断与归一化。

步骤 4：以长度 30 的滑动窗口生成输入序列，窗口末端 RUL 作为监督标签。

步骤 5：将每个时间步的传感器变量构造成图，通过动态 KNN 和 GAT 计算空间融合特征。

步骤 6：将空间特征序列输入 Mamba 编码器，提取长期退化状态和局部动态变化。

步骤 7：将编码器序列输出输入 Mamba 解码器，得到预测导向的融合特征。

步骤 8：由 interval_head 生成下界、上界和点预测权重，得到点预测以及未经校准的预测区间。

步骤 9：计算非对称点预测损失和 CQR Pinball 区间损失，并按照 xi 加权得到总损失。

步骤 10：通过 RMSprop 等优化器更新 GAT、Mamba、预测头和相关参数，并结合学习率调度和早停策略选择最佳模型。

步骤 11：在独立校准数据上计算区间非一致性分数，取得 conformal 校准半径。

推理阶段的流程为：

步骤 1：获取某台发动机最近 L 个周期的传感器观测。

步骤 2：使用训练阶段保存的标准化参数和相同的平滑设置进行预处理。

步骤 3：依次经过 GAT、Mamba 编码器和 Mamba 解码器。

步骤 4：输出归一化点预测、上下分位数和区间宽度。

步骤 5：使用校准半径对上下界进行扩展，并将结果恢复到实际 RUL 周期尺度。

步骤 6：输出最终结果，例如：

	点预测 RUL：35.2 个周期
	CQR 预测区间：[28.7, 43.9] 个周期
	区间宽度：15.2 个周期

在部署系统中，可以根据点预测安排维护优先级，也可以根据区间宽度制定风险等级：区间较窄表示模型较确定，区间较宽则表示需要更多观测、人工检查或更保守的维护策略。


九、评价指标与实验意义
----------------------------------------------------------------------

9.1 点预测指标

点预测可以使用 RMSE、MAE 和 NASA C-MAPSS 常用的非对称 Score 进行评价。RMSE 对较大误差更加敏感，MAE 反映平均绝对误差，Score 则对高估和低估施加不同的指数惩罚，更符合 RUL 任务中的风险导向评价。

Score 的一般形式可以表示为：

	S = sum_i [exp(-e_i / 13) - 1],       e_i < 0
		[exp( e_i / 10) - 1],             e_i >= 0

其中 e_i 通常表示预测 RUL 与真实 RUL 的差异。具体符号约定应与实验代码保持一致，但其共同特点是：不同方向的误差惩罚不同。因此，训练阶段引入 Asymmetric Loss，能够在优化目标层面与 Score 的风险属性形成呼应。

9.2 区间预测指标

对于 CQR 区间，不能只看区间是否足够宽，还需要同时评价覆盖率和紧致性：

	PICP：Prediction Interval Coverage Probability，真实值落入区间的比例；
	PINAW：Prediction Interval Normalized Average Width，归一化平均区间宽度；
	Interval Score：同时惩罚区间宽度以及真实值落在区间外的程度。

理想模型应在达到目标覆盖率的同时保持区间尽可能窄。区间过窄可能导致 PICP 下降，区间过宽虽然覆盖率高，但无法为维护人员提供有用的精确判断。CQR 的优势正是将区间覆盖和实际残差校准结合起来，在两者之间进行平衡。

9.3 可靠性评价

可靠性不能只用 RMSE 表示，还应从以下方面综合分析：

1. 覆盖率是否接近预设目标，例如 90% 或 95%；
2. 不同 RUL 阶段的区间宽度是否合理；
3. 低 RUL 样本是否存在系统性高估；
4. FD002 和 FD004 多工况数据上的区间是否明显变宽；
5. 预测误差较大的样本是否同时对应较宽区间；
6. 模型在不同随机种子下的点预测和区间指标是否稳定。

如果一个模型 RMSE 较低但在退化后期经常高估 RUL，或者其区间覆盖率严重不足，那么它仍然不适合作为高风险维护系统的唯一依据。本文模型的目标是同时获得较好的点预测精度、较低的风险型 Score 和可信的预测区间。


十、模型创新点总结
----------------------------------------------------------------------

本文方法的主要创新和贡献可以概括为以下几个方面：

1. 空间-时间联合建模。使用 GAT 建模多传感器变量之间的动态关联，使用 Mamba 建模长时间退化序列，形成空间信息和时间信息互补的特征提取框架。

2. Mamba 编解码器结构。使用 Mamba 替代传统 LSTM 作为主要时序建模模块，缓解递归结构在长序列建模中的信息衰减问题，并增强对全局退化趋势和局部波动的表达能力。

3. 风险自适应点预测。通过 Asymmetric Loss 对高估和低估施加不同惩罚，并对低 RUL 退化阶段提高关注程度，使模型优化目标更加符合航空发动机维护中的风险差异。

4. CQR 预测区间。通过上下分位数和 Pinball Loss 学习非对称区间，再利用校准集残差进行 conformal 校准，减少对 Gaussian 分布假设的依赖，提高有限样本下区间覆盖的可信程度。

5. 点预测与区间预测联合优化。模型不再只输出一个 RUL 数值，而是同时学习点预测和预测区间，使预测结果既可以用于寿命排序和维护决策，也可以用于风险等级判断。

6. 面向复杂工况的可靠性表达。对于 FD002 和 FD004 等多工况数据，CQR 可以根据实际残差适应不同样本的困难程度，使复杂工况、传感器噪声和训练样本覆盖不足带来的风险在区间宽度中体现出来。


十一、需要严格区分的概念
----------------------------------------------------------------------

第一，CQR 不等同于 Gaussian Loss。CQR 的核心是分位数回归加共形校准，主要输出上下分位数区间；Gaussian Loss 的核心是学习均值和方差，并依赖正态分布假设。二者都可以表达不确定性，但统计假设和训练目标不同。

第二，CQR 不等同于 MC Dropout。MC Dropout 通过多次随机前向传播估计预测波动，CQR 通常一次前向传播即可得到区间，再用校准数据修正覆盖范围。

第三，CQR 的点预测不一定是严格意义上的条件均值。当前实现中的 point 是由预测上下界和可学习权重得到的区间内点估计，因此论文中建议使用“点预测值”“中心预测”或“RUL 点估计”，不要直接写成“Gaussian 均值”。

第四，区间覆盖率和区间宽度需要一起解释。一个无限宽的区间可能覆盖所有真实值，但没有实际决策价值；一个极窄的区间可能看起来精确，却会频繁漏掉真实 RUL。可靠预测应在覆盖率、紧致性和风险惩罚之间取得平衡。


十二、总结
----------------------------------------------------------------------

总体而言，本文提出的 GAT-Mamba-CQR 框架是针对航空发动机 RUL 预测实际困难而设计的可靠性导向方法。GAT 解决多传感器空间关联问题，Mamba 解决长时间退化序列建模问题，非对称损失解决高估与低估风险不一致问题，CQR 解决单一预测值无法表达可信程度以及参数化分布假设可能失配的问题。

该模型的核心思想可以概括为：先利用 GAT 将多传感器观测转化为空间关联特征，再利用 Mamba 对退化过程进行长时序建模，之后通过非对称损失学习风险敏感的 RUL 点预测，同时通过 Pinball Loss 学习上下分位数，并使用 CQR 校准得到具有目标覆盖能力的预测区间。最终模型输出的不只是“发动机还剩多少个周期”，还包括“这个结果可能偏差多大、在什么范围内可信”。

因此，本文方法实现了从传统精度导向的点预测，向融合预测精度、风险敏感性和不确定性量化的可靠性导向 RUL 预测转变。该设计尤其适用于 NASA C-MAPSS 中存在多工况、多故障模式和传感器噪声的场景，并有望在 RMSE、MAE、NASA Score、PICP、PINAW 以及综合区间得分之间取得更合理的平衡。
